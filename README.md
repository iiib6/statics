# مشروع التحليل الإحصائي لبحث التخرج (Statistical Analysis Project)

مشروع التحليل الإحصائي الطبي والأكاديمي لبحث التخرج، متضمناً معالجة البيانات، التحقق الإحصائي المتقدم وفق أعلى معايير النشر في مجلات طب الأسنان المفهرسة عالمياً (Scopus Q1/Q2).

## التعديلات المنهجية والإحصائية المعتمدة (Methodological & Editorial Rigor)
1. **معالجة تداخل البيانات العنقودية (Clustering within Child):**
   - إضافة تحليل حساسية متقدم بنماذج **Generalized Estimating Equations (GEE)** لحساب الارتباط الداخلي للأسنان المتعددة داخل الطفل الواحد (40 طفلاً، 118 سناً).
   - تأكيد أن فروق الأضراس (Molars vs Premolars: GEE $p = 0.005$) والعمر (> 10 vs $\le$ 10: GEE $p = 0.0003$) تظل دالة إحصائياً بشكل قاطع حتى بعد ضبط العناقيد.
2. **اختبار علاقة الثبات بالتسوس (Fisher-Freeman-Halton Exact Test):**
   - اعتماد اختبار فيشر الدقيق كاختبار أساسي نظراً لوجود خلايا صفرية وتكرارات متوقعة أقل من 5 ($p < 0.0001$، الاحتمال الدقيق $5.75 \times 10^{-9}$)، مع إبقاء Chi-Square كدعم ثانوي ($\chi^2 = 118.00$).
3. **صياغة استدلالية رصينة (Association vs Causal Prevention):**
   - تعديل العبارات من جزم سببي ("Confirms prevention") إلى إثبات ارتباط سريري دال ("Statistically significant association with 3-month caries incidence").
4. **تنقيح التفسير السريري للأضراس:**
   - استبعاد فرضية قناة الغدة النكفية، والاعتماد على العوامل الموثقة سريرياً: صعوبة العزل، تجمع اللعاب في الردهة الخلفية، حركة اللسان، وعمق التعرجات المعقدة.
5. **ضبط جدول 6 (Kruskal-Wallis Test):**
   - تحديد اختبار Kruskal-Wallis غير المعلمي الدقيق لمقارنة مؤشرات DMFT ($H = 0.566, p = 0.753$) و DMFS ($H = 0.601, p = 0.740$) عبر فئات الثبات الثلاث.
6. **دقة مصطلح معدل الثبات:**
   - التمييز الصريح بين الثبات التام Complete Retention ($72.0\%$) والثبات المقبول/التراكمي Satisfactory Retention ($95.8\%$).
