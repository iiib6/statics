# مشروع التحليل الإحصائي لبحث التخرج (Statistical Analysis Project)

مشروع التحليل الإحصائي الطبي والأكاديمي لبحث التخرج، متضمناً معالجة البيانات، التحقق الإحصائي المتقدم، استخراج التقارير والرسوم البيانية.

## محتويات المشروع (Project Contents)
- **ملفات البيانات والمصادر:**
  - `NOOR_120.xlsx`: بيانات العينة (120 حالة).
  - `بحث.pdf`: نص البحث المرجعي.
  - `رسالة_الدكتورة.txt`: ملاحظات ومتطلبات التحليل الإحصائي.
- **سكربتات التحليل الإحصائي والأتمتة (Python Scripts):**
  - `run_stats.py`: التحليلات الإحصائية الوصفية والاستدلالية.
  - `verify_all_stats.py`: فحص ومطابقة جميع المؤشرات الإحصائية.
  - `generate_doctor_report.py`: إعداد وطباعة تقرير الملاحظات الطبية والإحصائية.
  - `generate_docx_report.py`: إنشاء التقرير النهائي بصيغة Word.
  - `generate_statistical_guide.py`: الدليل الإحصائي الشامل ومطابقة المتطلبات.
- **المخرجات والتقارير والرسوم:**
  - `Scopus_Statistical_Report_Final.docx`: التقرير الإحصائي النهائي المعتمد لمعايير Scopus.
  - `figure1_retention_tooth_type.png`: رسم بياني لنسبة الثبات حسب نوع السن.
  - `figure2_retention_jaw_location.png`: رسم بياني لنسبة الثبات حسب موقع الفك.
